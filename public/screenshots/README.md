Drop your website screenshots into this folder (`/public/screenshots/`). The portfolio application will automatically display them as interactive desktop browser previews on both the project cards and inside the full-screen case study inspection modals.

## Recommended Dimensions
- **Resolution**: 1600 × 1000px or 1920 × 1080px (16:9 or 16:10 aspect ratio)
- **Quality**: Clear desktop view showing hero and key sections
- **Fallback**: If an image is not uploaded yet, an elegant responsive placeholder with brand accents and specs is automatically displayed.
